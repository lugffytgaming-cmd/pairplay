# PairPlay v0.9

- Language switch now updates the visible web UI for English, বাংলা, and हिन्दी.
- PairPlay name is unchanged.

## Mobile testing
Open the deployed public HTTPS URL on a phone. No shared Wi-Fi and no IP address are required. Custom room links include the room code in the URL.
